# Complex

An AI-powered desktop client that combines three models —
one analyzes, one criticizes, one synthesizes.

<img width="1280" height="720" alt="ComplexHeader" src="https://github.com/user-attachments/assets/2dd02d97-de4c-42ab-9093-106df7110907" />


## Features
- Three AI models working together
- Chat history saved locally
- File upload support
- Customizable design

## Setup

1. Clone the repository
2. Install dependencies:
   npm install
3. Start the app:
   npm start

## Requirements
- Node.js
- OpenRouter API Key (https://openrouter.ai)

## Build
npm run build
